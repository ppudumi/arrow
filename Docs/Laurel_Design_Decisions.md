# 라우랄 — 개발상 임시 결정 목록

기획 자료에 없거나 불명확해서 개발 중에 정한 규칙과 수치입니다. **확정 기획이 아닙니다.**
각 항목에 이유와 조정 위치를 적었습니다. 수치는 대부분 `Assets/Laurel/Resources/LaurelData/*.json` 에서 바꿀 수 있고, 코드를 고칠 필요가 없습니다.

판단 우선순위: 사용자 지시 → Notion 최신 보충(05 문서의 답변) → Notion 확정 기획 → 엑셀 초안 → 궁술테스트 빌드 동작.

## 1. 확정 결정을 그대로 반영한 항목 (임시 아님)

- 튜토리얼 뱀 이름: **파에톤** (엑셀의 파이톤·파이썬 표기는 쓰지 않음).
- 튜토리얼 → 파에톤 처치 → 저주 → 본게임. 저주 후 능력치가 본게임 기본 상태.
- 노드로 이루어진 스테이지, 작은 정사각형 맵, 1→2→3스테이지는 로비를 거치지 않고 진행.
- 어디서 죽든 로비, 재도전은 1스테이지 처음부터. 돈·화살·유물·도전 중 능력치·일시 효과 전부 초기화.
- 넥타르(미사용분 포함)·넥타르 강화·보스 해금 자격·구매 스킬은 영구 저장.
- 보스 클리어 → 구매 자격 해금 → 로비에서 넥타르로 구매 → 영구 보유. 자동 지급 없음.
- 발사 5종 × 회수 6종 독립 조합(30).
- 동시 회수는 무작위, 순차 회수는 회수 순서로 화살통에 배치.
- 화살 43항목 중 분노 8↔9, 이카루스 13↔14 는 **변형 상태**. 독립 화살은 41종.

## 5. 화살 효과 해석

### 무한 발동·중복 복제 방지

- 화살통으로 들어가는 길은 `PlayerCombat.TryRecover` 하나, 나가는 길은 `ArrowQuiver.TakeNext` 하나. 매 프레임 화살통 수·상태·덱 수를 검사(위반 시 기록).
- 임시 투사체(삼살·거울·분열·파열·바이러스·하데스)는 **카드가 아님**: 화살통에 들어오지 않고, 다른 임시 투사체를 만들지 않음(파열·분열·재발사 효과 무시). 동시 최대 160발.
- 광역 피해(폭발·공명·스태틱·번개·장판)는 '화살 적중'이 아니므로 적중 효과를 다시 일으키지 않음.
- 아레스 뽑기 재적중은 박힌 화살마다 정확히 1회 후 회수.
- 에코는 에코를 복사하지 않음. 이카루스 변형은 비행당 최대 4회.

## 6. 상태이상 공통

- 같은 상태이상은 중첩하지 않고 **더 긴 지속시간으로 갱신**. 재앙(횟수)·스태틱(스택)만 누적.
- 보스: 지속시간 ×0.5, 감속·끌어당김 효과 ×0.5, 넉백 ×0.15.
- 조정: `balance.json → status`.

## 8. 적·보스 (엑셀 적 시트는 비어 있음)

- 일반 적 11종: 순찰(들풀 정령), 돌진(새끼 멧돼지·월계수 골렘), 비행(까마귀·님프·큐피드), 원거리(사티로스·하르피아), 도약(두꺼비), 포탑(갈대 사수·가시 덩굴). 정예는 체력 ×2.6, 피해 ×1.25, 크기 ×1.3.
- 보스: 1 칼리돈의 멧돼지(돌진→벽 충돌 낙석, 도약 내려찍기 충격파, 돌 흩뿌리기), 2 강의 신 아켈로오스(물줄기 연사, 바닥 해일, 님프 소환, 2페이즈 폭우), 3 사랑의 신 에로스(황금 화살 원형, 납 화살, 급강하, 2페이즈 추적 화살·큐피드 소환). 체력 50% 이하 2페이즈.
- 보스 체력: 240 / 400 / 540 (초반 화력 7/발 기준). 조정: `enemies.json → bosses`.
- 스토리: 엑셀 순서(뱀 처치 → 에로스 조롱 → 금/납 화살 → 다프네 추적 → 강의 신 → 월계수)를 3스테이지까지 배치, '다음 장에서 계속'으로 끝남. 에로스를 때려 저주를 푸는 아이디어는 3스테이지 보스로만 반영(저주는 아직 풀리지 않음).

## 9. 연출·UI·기타

- 적·지형·이펙트 그래픽은 런타임 도형(아트 자산 없음). 플레이어는 기존 프리팹 그대로.
- 효과음은 런타임 합성(기존 Nujabes BGM·SFX 는 정리 대상이라 제외).
- UI 는 IMGUI(1920×1080 기준 비율), 한글은 OS 폰트(Apple SD Gothic Neo / 맑은 고딕 등).
- 카메라: 일반 방 크기 7, 보스방 9 + 플레이어와 보스 사이를 비춤. 지형은 플레이어 허리 리본보다 앞에 그려 바닥 아래로 늘어진 끝을 가림.
- 로비 수련장: 고른 궁술 조합을 허수아비로 시험(도전과 무관).
- 개발자 모드(F12): F9 넥타르 +20, F10 방 정리, F11 보스 해금 전체. 검증·시연용.
